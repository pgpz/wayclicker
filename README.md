# wayclicker
wayland autoclicker


# how to install
1) `git clone https://github.com/pgpz/wayclicker.git`
2) `cd wayclicker`
3) `sudo make install`

use `which wayclicker` to see if it installed

# use
open terminal & type `wayclicker`


use `man wayclicker` if you need assistance!

bug reports and changes welcome
